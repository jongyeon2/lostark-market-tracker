# Phase 28-01 — 보석 카테고리 흡수 (DASH-01)

`/gems`는 **6개 값을 보여주려고 페이지 하나**를 쓰고 있었다. 상단내비 한 칸과 라우트 하나를 쓰면서
정작 대시보드의 카테고리 필터와는 무관하게 떨어져 있었다. 보석을 카테고리로 넣으면 사용자가 이미
쓰는 필터 안에 자연스럽게 들어간다(사용자 재설계 2026-07-15).

## 설계 결정 (UI-SPEC 요약)

**보석은 단독 항목이다**(사용자 결정). `보석 > 티어4 보석`은 말이 겹쳐 군더더기고,
`보석 > 겁화/작열`은 "6종 한 번에"와 어긋난다.

**`filterByCategory`는 보석을 모른다.** 그 함수는 `TrackedItem[]` 필터이고 **보석은 `TrackedItem`이
아니다**(경매장 · `Id` 없음 · 다른 API). 억지로 끼우면 `TrackedItem` 모양의 가짜 보석을 만들어야
한다. 분기는 `DashboardPage`가 `selectedId === GEM_CATEGORY_ID`로 한다 — **타입이 진실을 말하게 둔다.**

**`GemCard`는 `ItemCard`를 재사용하지 않는다.** 배치(아이콘+이름 좌 / 가격 우)만 승계하고
상호작용은 승계하지 않는다. `ItemCard`에 "보석이면 안 눌림" 분기를 더하면 물품 카드가 자기와
무관한 조건을 지고 다닌다.

## Tasks

### Task 1 — `categories.ts` 보석 leaf

**name:** 보석 카테고리 정의
**action:** `group`을 nullable로 넓히고 보석 leaf를 맨 뒤에 추가.

**files:** `frontend/src/features/dashboard/categories.ts` (수정)

- `export const GEM_CATEGORY_ID = 'gems'`
- `Category.group: CategoryGroup | null`
- `deriveCategories(items, gemCount = 0)` — `gemCount > 0`일 때만 보석 leaf를 **맨 뒤**에 append.
  빈 leaf를 안 그리는 기존 규율 그대로: 보석이 0건/실패면 카테고리 자체가 없다.
- `filterByCategory`·`groupIconUrl`·`CATEGORY_DEFS` **무변경**(보석은 `CategoryDef`가 아니다 —
  `match` 술어가 성립하지 않는다).

**verify:** `npm run build` 그린.

### Task 2 — `CategoryNav` 단독 항목 렌더

**name:** 그룹 없는 leaf 지원
**action:** 그룹 루프 뒤에 `group === null` leaf를 헤더 없이 `NavLeaf`로 렌더.

**files:** `frontend/src/features/dashboard/CategoryNav.tsx` (수정)

- 데스크톱: 기존 `GROUP_ORDER` 루프 유지 + 그 뒤에 ungrouped leaves 렌더(`space-y-4`가 이미 분리를 준다).
- 모바일 칩: **0줄** — 칩 행은 이미 그룹을 무시하고 leaf만 평평히 그린다. 보석 칩이 자동으로 붙는다.
- `NavLeaf`·`Chip`·활성 표시·`aria-current` **무변경**.

**verify:** `npm run build` 그린 + Task 5 렌더 검증.

### Task 3 — `GemCard` 신규

**name:** 안 눌리는 보석 카드
**action:** `GemPage`의 `GemPriceCell`·`GemIcon`을 **로직 그대로** 이주. 카드 배치는 `ItemCard` 승계.

**files:** `frontend/src/features/dashboard/GemCard.tsx` (신규)

- 루트 `<Card>` + `<CardContent className="flex items-center justify-between">`, `<div>` — **링크·버튼 아님**.
  `hover:shadow-md`·`cursor-pointer` **없음**.
- 이름: `{gem.level}레벨 {gem.series}` (예: "8레벨 겁화" — 사용자 확인 2026-07-15).
  `displayName`("8레벨")은 계열 그룹 헤더가 있던 Phase 26 전제라 여기선 부족하다.
- 가격/아이콘/문구 3상태: `GemPage`에서 **그대로** 옮긴다(값 지어내기 금지 유지).

**verify:** `npm run build` 그린.
