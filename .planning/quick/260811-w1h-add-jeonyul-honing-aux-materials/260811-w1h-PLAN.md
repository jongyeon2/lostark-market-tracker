# Quick Task 260811-w1h — 신규 재련보조 '전율' 재련재료 편입

## 왜

2026-08-05 벨가르딘 그림자 레이드 출시로 **일반 장비 재련 보조 재료 '전율' 계열**이 신규 추가됐다.
거래소(MARKETS)에서 가져올 수 있는지 확인하고, 가져올 수 있으면 워치리스트에 편입해 10분 시계열
수집 대상에 넣는다. (기존 업화 [19-20]는 이미 편입됨 — 신규는 '전율'뿐. 사용자 도메인 확인.)

## 스파이크 실측 (거래소 /markets/items, CategoryCode 50020, 2026-08-11)

이름검색 '전율' DESC+ASC로 실측 — 공개 메타데이터(Id/Name/Grade/Icon)만, 가격·키 미출력.
`LOSTARK_API_KEY`(.env)로 HTTP 200 확인(Docker 꺼져 있어 Spring 스파이크 테스트 대신 동일 계약의
직접 호출 스크립트로 실측; 재현용 스파이크 메서드는 `MarketsApiSpikeTest.captureAwakenHoningTiers()`로 잠금).

## 핵심 설계 결정

- 🔑 **마이그레이션 없음.** WatchlistSeeder는 insert-if-absent(`findByExternalItemId(...).orElseGet(save)`)라
  **신규 external_item_id는 다음 기동 시 dev·prod 모두 자동 insert**된다. V7이 마이그레이션을 쓴 건 *기존*
  행의 item_group을 바꾸는(seeder가 못 건드리는) 경우였고, 코드베이스에 아이템 insert용 마이그레이션은
  전무하다 — 모든 아이템 추가는 seeder를 통한다. 신규 편입에 마이그레이션은 중복·비관용적.
- **item_group=재련보조** (사용자 확정): 업화와 같은 일반 재련 성공률 보조 재료. 프론트 `_shared/categories`의
  MATERIAL_GROUPS에 이미 '재련보조' leaf가 있어 **프론트 변경 0** — 재련보조 카운트만 6→10으로 오른다.

## 작업

1. **`WatchlistSeeder.java`**: 재련 보조 섹션(업화 [19-20] 다음)에 전율 4종 추가 + 클래스 주석 개수 갱신
   (49→53, MATERIAL 31→35, 재련보조 6→10, 아이콘 공유 목록에 전율 추가).
2. **`WatchlistSeederIT.java`**: 단언 갱신 — hasSize(49→53), MATERIAL(31→35), 재련보조(6→10),
   count(49→53) ×2, 전율 샘플 1건 추가(66112564 재봉술 전율 [12-15]).
3. **`MarketsApiSpikeTest.java`**: `captureAwakenHoningTiers()` @Test(@Disabled 상속) 추가 — 실측 provenance
   잠금(captureRefineMasterBooks 선례, 50020 이름검색 '전율'/'강화' DESC+ASC → UTF-8 파일).
