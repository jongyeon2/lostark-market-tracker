# Quick 260715-g98 — 재료 망치 아이콘 + 쿠폰 기간 렌더

## 배경

**(1) 재료 아이콘** — quick-260715-nav에서 각인서 헤더에만 아이콘을 넣었다(18종이 전부 같은
`use_9_25.png`라 대표성이 성립). 재료는 품목마다 아이콘이 달라 **데이터에서 대표 아이콘을 뽑을 수
없다** → 사용자 요청대로 lucide `Hammer` 글리프를 쓴다. Phase 14 `ItemIcon` fallback이 lucide 글리프
(ScrollText/FlaskConical/Package)를 쓰는 선례가 있다.

**(2) 쿠폰 기간** — `coupon` 테이블엔 `code`/`reward`/`expires_at`뿐이고 **시작일 컬럼이 없다**.
렌더만 바꿀 수 없고 마이그레이션 → 엔티티 → DTO → 어드민 폼 → 렌더까지 세로 슬라이스가 필요하다.

## 결정

**`starts_at`은 nullable(선택 입력)** — 이미 등록된 쿠폰(운영 `2026로아온썸머감사선물`)엔 시작일이
없다. `NOT NULL` + 백필은 **없는 날짜를 지어내는 것**이라 이 프로젝트의 정직성 원칙에 어긋난다.
비어 있으면 `~ 2026.09.16`, 채우면 `2026.07.01 ~ 2026.09.16`으로 렌더한다.

**`startsAt <= expiresAt` 검증** — 렌더가 순서를 전제하므로 뒤집힌 입력은 400으로 막는다.
