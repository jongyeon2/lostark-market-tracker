# PLAN — 카테고리 sticky 가림 수정 + 물품 박스 8칸

사용자 피드백 2건. **프론트 CSS만** — 백엔드 0줄, 마이그레이션 0, 데이터·동작 무변경.

## 목표

1. 스크롤 시 `각인서` 그룹 헤더가 상단바 뒤로 사라지지 않게 한다.
2. 물품 박스를 8칸까지 보이게 키우되, 물품이 적은 카테고리에 빈칸이 생기지 않게 한다.

## 1. 카테고리 sticky 오프셋 (`CategoryNav.tsx`)

### 원인 (라이브 실측 2026-07-16, 1920×1000, 배포본)

| 요소 | 값 |
|---|---|
| `TopNav` | `sticky top-0` · `h-14`(56px) · `z-40` · `bg-card`(불투명) |
| `CategoryNav` | `lg:sticky lg:top-6`(24px) · `z-auto` |
| `각인서` h2 (scrollY=400) | top **24** / bottom **51** / height **27** |

멈춤 지점 24px가 상단바 영역(0~56px) **안쪽**이다. h2(24~51px)는 56px 아래로 내려오지 못해
**27px 중 27px, 즉 100%가 상단바 뒤에 깔린다.** 헤더가 스크롤을 안 따라오는 게 아니라 —
따라오는데 불투명한 바 **밑에** 있다. 그래서 첫 leaf(`딜러 각인`)부터 보인다.

### 수정

`lg:top-6` → **`lg:top-20`** (80px = 상단바 56 + 기존 여백 24).

**z-index로 덮지 않는다.** nav를 상단바 위로 올리면 헤더가 *보이긴* 하나 상단바를 가리는
새 버그가 된다. 겹침 자체를 없애는 게 맞다.

주석에 **80 = 56 + 24이며 `TopNav`의 `h-14`에 종속**임을 남긴다. 상단바 높이가 바뀌면 이 값도
같이 바뀌어야 하는데, 코드만 봐선 알 수 없다.

## 2. 물품 박스 8칸 (`DashboardPage.tsx`)

### 실측 (같은 세션)

카드 **68px** 균일 · 간격 **12px** · 현재 박스 468px(`scrollHeight` 868 = 11×68 + 10×12 ✓)

**8칸 = 8×68 + 7×12 = 544 + 84 = 628px**

### 고정이 아니라 max — 사용자 결정 2026-07-16

카테고리별 물품 수: 딜러각인 **11** / 서포터각인 **7** / 재련재료 **11** / 상급재련 **8** /
재련보조 **6** / 아크그리드젬 **6**.

628px로 **고정**하면 6개짜리 카테고리는 468px만 차고 **160px가 빈다**. 답답한 걸 고치려다
허전해지는 맞교환이라 사용자에게 물었고 → **내용만큼 줄어드는 쪽** 선택.

`lg:h-[628px]` → **`lg:max-h-[628px]`**: 8칸 이상이면 628px에서 스크롤 시작, 그 미만이면 내용만큼.

**대가(사용자 인지·수용):** 카테고리를 바꾸면 아래 `이벤트 영향`의 세로 위치가 움직인다.
어차피 목록 전체가 바뀌는 순간이고, 468px 고정을 택했던 이유(카드가 중간에 잘림)는 max에선
발생하지 않는다 — max는 항상 카드 경계에서 끊기지 않지만 **스크롤 컨테이너라 잘림이 곧 스크롤**이다.

### 이름·주석 정정

상수명 `ITEM_BOX_HEIGHT`는 이제 **높이가 아니라 상한**을 뜻한다 → `ITEM_BOX_MAX_HEIGHT`.
기존 주석은 "6장 · 468 = 6×68+5×12 · 옆 소식 패널에 맞추지 않는 이유"를 설명하는데 전부 낡았다.
8칸·max 근거로 다시 쓴다.
