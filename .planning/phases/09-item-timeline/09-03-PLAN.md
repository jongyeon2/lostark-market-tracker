<objective>
Build the **time-range state layer** for the timeline: a URL-as-state hook and the preset/date controls that drive it. Together they satisfy the "user can change from/to" half of TIME-05 and lock D-03 (default 30-day window) and D-04 (presets + date inputs + URL searchParams).

The engineering signal is **off-by-9h discipline pushed to the input boundary**: the chart axis already positions on raw UTC epoch and labels in KST (Phase-7 D-09); here the same rule governs the date picker — the user sees/edits a KST calendar date while the URL and the request carry UTC instants. The hook keeps all router knowledge in one place so the controls stay a dumb controlled component reusable by Phase 10.
