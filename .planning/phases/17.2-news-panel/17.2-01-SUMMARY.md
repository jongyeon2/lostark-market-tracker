## Decisions Made
- **날짜 통과(문자열):** StartDate/EndDate/RewardDate/Date 모두 오프셋 없는 ISO-8601 local → 백엔드 `LocalDateTime` 파싱 없이 String 통과, 프론트가 표시 포맷팅(정렬은 ISO-8601 문자열 비교로 안전).
- **Type 미잠금(String):** notices `Type`은 한글 분류(≥4 distinct 관측) — enum 잠그지 않고 String 통과, 프론트가 값별 뱃지 색 + 미지값 기본 스타일.
- **RewardDate nullable:** 일부 이벤트는 보상일 부재 가능 → DTO nullable.

## Deviations from Plan
- 없음. 플랜대로 2태스크 완주, 스코프 크리프 0.
- **워크플로우 확인:** 라이브 외부 호출(실 크리덴셜) 시점에 사용자 확인(AskUserQuestion) → "내가 지금 실행" 승인 후 진행. 플랜 태스크 변경 없음.

## Issues Encountered
- **Type 한글 값 복구 불가(비핵심):** 콘솔 인코딩(CP949)→XML `<system-out>` 단계에서 한글이 U+FFFD로 치환 → 정확한 Type enum 문자열 이 세션에서 복구 불가. field NAME·타입(string)·distinct 수(≥4)는 측정 확정. Type이 String 통과 필드라 DTO 잠금엔 무영향.
- Gradle test stdout이 콘솔 미노출 → `build/test-results/test/TEST-*.xml` `<system-out>`에서 회수(17.1 선례).
- build.gradle의 .env 로딩은 bootRun 전용(test 미주입) → 키를 값 출력 없이 셸 env로 주입(길이만 로그) 후 `cleanTest test --tests …captureNewsFields`로 단일 메서드 타겟.
