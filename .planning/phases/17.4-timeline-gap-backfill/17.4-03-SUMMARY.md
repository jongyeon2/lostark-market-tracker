# Phase 17.4-03: 상세 Stats 재료 14일 소급 러너 Summary

**서버 기동 + 일 1회, 상세 API `Stats[]`(AvgPrice>0)로 재료 최근 14일 일별 평균을 `DETAIL_STATS`로 멱등 소급 — 재료 한정·레이트리밋 존중·품목별 fail-open, 수집 핵심 경로 0줄.**

## Accomplishments
- `LostarkApiClient.getItemDetail(long)`: read-only GET `/markets/items/{id}`, `searchMarketItems`와 **동일한 에러 택소노미**(401/403→Auth, 429→RateLimited+Retry-After, 5xx/I-O→Transient, 4xx→NonRetryable).
- `ItemDetailResponse`(Stats[] null-guard) + `MarketStat`(Date/AvgPrice/TradeCount) DTO.
- `TrackedItemRepository.findByActiveTrueAndRoleGroup` — 재료(MATERIAL) 한정 finder.
- `DetailStatsBackfillRunner`: `ApplicationRunner`(기동) + `@Scheduled(cron)`(일1회)로 재료 순회 → `Stats[].AvgPrice>0`만 `DETAIL_STATS` 멱등 upsert. `tryAcquire` 미획득 시 skip, `AuthApiException`은 회차 break, 그 외 RuntimeException은 품목별 fail-open.
- `DetailStatsBackfillRunnerIT`(3 tests): AvgPrice=0 skip(14→13행)·멱등(재실행 13행 유지)·각인서 미호출을 Testcontainers로 증명.

## Decisions Made
- **`@Profile("!test")`** — 러너의 `run()`이 매 테스트 컨텍스트 startup마다 실 `getItemDetail`를 호출하는 위험(공유 DB의 leftover MATERIAL) 차단. `WatchlistSeeder`(@Profile dev/seed) 선례. IT는 러너를 수동 생성해 `backfill()` 직접 구동.
- **Clock 생략** — 플랜 인터페이스의 Clock은 backfill()에서 사용되지 않음(모든 stat_date를 API `Stats[].Date`에서 파싱) → 죽은 의존성 제거.

## Deviations from Plan

### Auto-fixed Issues

**1. [Test-safety] 러너에 `@Profile("!test")` 추가**
- **Found during:** Task 2 (ApplicationRunner의 startup auto-fire 검토)
- **Issue:** @Component 러너가 모든 @SpringBootTest 컨텍스트 startup에서 run()→실 API 호출 시도(공유 Testcontainers DB에 다른 테스트가 남긴 MATERIAL 존재 가능) → fragile·실 네트워크

- **Verification:** `./gradlew build` 그린, DetailStatsBackfillRunnerIT 3/3 통과
