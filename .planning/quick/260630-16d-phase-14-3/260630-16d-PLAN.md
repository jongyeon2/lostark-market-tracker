# Quick 260630-16d: Phase 14 카드/셀렉터 비율 조정 3건

playwright 측정으로 근본 원인 확정 후 수정.

## 1. 대시보드 ItemCard — 아이콘·이름 과대

`ItemCard.tsx` CardTitle `text-xl`(20px) + ItemIcon `md`(32px)가 그리드 카드에서 과대.
잘리진 않으나(그리드가 wrap) 비율 큼. → 제목 `text-base`, 아이콘 `sm`(20px)로 축소.

## 2. LatestPriceCard — 카드가 텍스트 폭으로 확장 안 됨(잘림)

근본 원인: shadcn `CardHeader`의 `@container/card-header`(`container-type: inline-size`)가
inline-size를 contain → `w-fit` 카드가 nowrap 제목(282px)의 max-content를 부모로 전파받지
못하고 `min-w-56`(224px)에 고정, 제목이 오버플로해 잘림(측정: card width 224, title 282).
검증: header `container-type:normal` 시 카드 224→332px, 잘림 해소. → CardHeader에
`[container-type:normal]` 추가.

## 3. ItemSelect 트리거 — 선택값 truncation

드롭다운 목록 항목은 실측상 안 잘림(content 310px가 widest item 302px 수용, 1280·820 모두).
실제 잘림은 트리거(`w-56`=224px 고정 + line-clamp-1)의 선택값. → 트리거 `w-56`→`w-72`(288px).
