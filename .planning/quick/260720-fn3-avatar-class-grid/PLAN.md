# Quick Task 260720-fn3 — 아바타 직업 선택기 바둑판 그리드

## 배경 · 문제

아바타 페이지의 직업 선택은 shadcn `Select` 드롭다운 하나다. 30개 항목을 접힌 목록에서
텍스트로만 훑어야 해서, 로아 유저가 아는 방식(직업 아이콘)으로는 고를 수 없다.
사용자 요구: **드롭다운 폐기 → 아이콘 위 / 직업명 아래의 바둑판 타일**, 직업군 단위 3열 2줄.

## 사전 조사 결과 (2026-07-20, 실측)

- **공식 API는 직업 아이콘을 주지 않는다.** `GET /markets/options`의 `Classes`는 한글 문자열 30개뿐.
  직업군(전사/무도가/…) 분류도 없다. CDN 경로 추측도 전부 404.
- **공식 웹사이트 자산에는 있다.** `2018/obt/assets/css/pc.css`의 `background-image`가
  `/2018/obt/assets/images/common/class/{slug}.svg`를 가리키고, `assets/js/pc.js`에는
  `{root_ko, root_en, list:[{name_ko, name_en}]}` 구조의 **직업군↔클래스 원본 데이터**가 들어 있다.
  두 파일에서 뽑아낸 30개가 API의 30개와 1:1로 정확히 맞는다(추측 0행).
- 파일명 함정 확인: `souleater`(언더바 없음) / `dimension_master`(있음) / 가디언나이트는 `dragon_knight.svg`.
- 자산 확보 방식은 **번들**(사용자 결정). 아이템 아이콘처럼 CDN 핫링크하지 않는다 — 이 URL들은
  API가 준 값이 아니라 사이트 내부 자산이라 예고 없이 옮겨질 수 있다.

## 직업군 매핑 (공식 pc.js 추출, 성별 분리 7그룹으로 병합)

공식 데이터는 성별까지 쪼갠 11개 root(전사(남)/전사(여)/…)다. 화면에서 "전사(남)"과 "전사(여)"를
따로 세우면 3열 2줄이 깨지므로 **성별만 병합해 7그룹**으로 둔다. 클래스 구성원은 공식 그대로다.

| 직업군 | 클래스 (공식 순서) |

## 작업

### 1. 공식 클래스 SVG 30개 번들

`frontend/public/class-icons/{slug}.svg`로 내려받는다. 스크립트가 아니라 1회성 다운로드 —
자산은 커밋되고, 재실행할 일이 없다(신규 직업이 나오면 그때 한 개만 추가).
검증: 파일 30개, 모두 0바이트 초과, 모두 `<svg`로 시작(404 HTML이 섞이지 않았는지).

### 2. `frontend/src/features/market/classes.ts` 신설

- `CLASS_GROUPS`: 위 표를 그대로 담은 `{ label, classes: [{ name, slug }] }[]`.
- `groupClasses(apiClasses: readonly string[])`: **API가 준 목록이 단일 출처**.
  API에 있는 직업만 그리고, 표에 있으나 API에 없는 직업은 그리지 않는다.
  **표에 없는데 API에 새로 등장한 직업은 드롭하지 않고 `기타` 그룹으로 노출**한다 —
  신규 직업 출시일에 그 직업만 조용히 사라지는 게 최악이다(아이콘 없이 이름만 뜬다).
- 순수 함수만. 데이터 페칭·React 없음(대시보드 `categories.ts` 선례).

### 3. `AvatarPage`의 `Select` → `ClassGrid`

- shadcn `Select` import·마크업 제거.
- 직업군 블록 = 3열 2줄(`grid-cols-3`), 그 블록들을 화면 폭만큼 가로로 배열
  (`grid` + `sm:grid-cols-2 xl:grid-cols-3` 수준). 사용자 결정 2026-07-20:
  인벤식 세로 나열은 상단이 너무 길어져 시세 목록이 밀린다.
- 타일 = 아이콘(위) + 한글 직업명(아래), `<button>`.
- 선택 표시는 **색 하나에 의존 금지**(대시보드·PartNav와 동일 규율):
  배경 + 테두리 + `aria-pressed`.
- 아이콘 로드 실패 시 슬롯만 유지하고 조용히 비운다(`MarketIcon`/`GemIcon` 선례) — 이름은 남는다.
- 모바일은 열 수를 줄인다(블록 1개씩).

## 검증

- `cd frontend && npm run build` (`tsc -b && vite build`) 통과.
- 브라우저: 30개 타일이 7블록으로 뜨고, 클릭 시 기존 검색 흐름(부위·검색·정렬·페이지)이 그대로 동작.
