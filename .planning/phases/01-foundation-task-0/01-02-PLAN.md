| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | POST /api/items request body | mitigate | Bind to `TrackedItemRequest` DTO with bean validation (`@NotBlank`); never bind directly to the entity (no mass-assignment of id/active). |
| T-02-02 | Tampering | SQL injection via item fields | mitigate | All persistence via Spring Data JPA / parameterized queries; no string-concatenated SQL. Flyway DDL is static, not user-driven. |
