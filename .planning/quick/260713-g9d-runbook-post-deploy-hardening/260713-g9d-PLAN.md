## Task 1 — 런북 §4(a)·§8 갱신

**File:** `docs/deploy/oracle-vm-runbook.md`

**Action:**
1. **§4(a) SSH**: 표의 `<내 IP>/32` 아래에 운영 주의 note 추가 —
   유동 IP 시 재수정 필요, 심층 방어로 `PasswordAuthentication no`(키 전용) 권장.
2. **§8 라이브 체크리스트**: 보안 헤더/CSP 검증 항목 2개 추가 +
   배포된 헤더 목록(HSTS·nosniff·X-Frame·Referrer·**CSP·Permissions-Policy·COOP**, Server 제거)과
   `curl -sI | grep` 검증 명령 + 브라우저 CSP 위반은 무해한 eval 1건뿐이라는 설명(unsafe-eval 미포함 근거).
3. **§8 go-live note**: 게이트 밖 하드닝(CSP·SSH)도 적용됨을 명시.

**Verify:** 런북에 CSP·Permissions-Policy·COOP 헤더명과 curl 검증 절차가 명시되고,
SSH 유동 IP 주의가 추가됨. 마크다운 구조(표·코드블록·체크리스트) 유지.

**Done:** 재배포/신규 배포자가 런북만으로 하드닝 상태를 재현·검증할 수 있음.
