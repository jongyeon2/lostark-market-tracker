<objective>
Deliver the **admin CRUD layer** for game events (`POST/GET/PUT/DELETE /api/admin/events`, ADMIN-01) and watchlist items (`POST/DELETE /api/admin/items`, ADMIN-02) on the **already-locked `game_event` / `tracked_item` model**, plus the error-contract extensions they need. This wave builds the *capability*; plan 04-02 (Wave 2) puts the shared-secret gate in front of it.

Key behaviors: event create stamps `created_at`/`updated_at` via the entity's existing `@PrePersist`/`@PreUpdate` (D-07, Success Criterion 2); event PUT is a **full replace** that *allows `occurred_at` to change* (D-06) because the timeline overlap and Phase 5 event-impact anchor key off it. Item DELETE is a **soft delete** (`active=false`, D-03) so the time series and event-impact evidence survive the FK that has no `ON DELETE CASCADE`; it is idempotent and reflects instantly in `GET /api/items` (Success Criterion 3). Re-posting a soft-deleted `external_item_id` **reactivates** it; re-posting an active one is **409** (D-05). The old public `POST /api/items` is **removed** — the public surface becomes read-only (D-04). Request bodies bind DTOs (never entities) and `@Valid` failures return **400** through a new `MethodArgumentNotValidException` handler (D-10). A Flyway **V3** migration enforces `UNIQUE(external_item_id)` (D-05).

Purpose: This is the write/admin half of the pipeline — the surface a curator uses to keep the watchlist and the event log accurate. Soft-delete and full-replace-with-`occurred_at` are the data-integrity decisions that keep the downstream correlation honest, the showable "I thought about deletes and time-series provenance" signal. Every admin integration test sends the `X-Admin-Secret` header now (inert without Spring Security) so 04-02 can drop the gate in front with **zero test retrofit**.

Output: `GameEventRequest`/`GameEventResponse` DTOs; `GameEvent.replace(...)`; `AdminEventService` + `AdminEventController`; `AdminItemService` + `AdminItemController`; `ResourceNotFoundException` (404) + `DuplicateResourceException` (409) + a `MethodArgumentNotValidException` handler on `ApiExceptionHandler`; a slimmed read-only `ItemController` (public POST removed); a Flyway `V3` UNIQUE migration; an `AdminAuth` test helper; and two Testcontainers ITs plus the updated `SchemaRoundTripIT`.
</objective>
