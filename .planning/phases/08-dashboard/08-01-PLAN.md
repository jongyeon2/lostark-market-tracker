<objective>
Build the **status presentation primitives** that DASH-02 hangs on, before any data card consumes them. Two purely-presentational components: **`StatusBadge`**, which maps the four backend-measured `status` values to a single badge (semantic color + Korean label + lucide icon) per the 08-UI-SPEC Status Badge Mapping — `SUCCESS`/`PARTIAL_SUCCESS`/`FAILED`/`NO_RUNS` as four distinct grades plus an unknown→neutral fallback that shows the raw status string (D-05) — and **`SummaryMarker`**, which renders the optional `summaryMessage` diagnostic marker (`AUTH_ERROR`→'인증 오류', `RATE_LIMITED`→'레이트리밋', `null`→nothing) as a categorical label only, never a secret (D-06). First add the shadcn **`badge`** block (deferred from 07-01) from the official registry.

The engineering signal is **the front end continuing the project's honest-data ethos**: it reads the real status domain out of `PriceCollector.java`/`CollectionHealthResponse.java` and renders the grade ROADMAP forgot (`FAILED` = 위험) as its own band, degrades unknown values to a readable label instead of hiding them, and proves at the type level that no secret can reach the screen because the response shape has none. These primitives are consumed by 08-02 (HealthCard); nothing fetches data here.

Output: `src/components/ui/badge.tsx` (shadcn add) + `src/features/dashboard/StatusBadge.tsx` + `src/features/dashboard/SummaryMarker.tsx`.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-0801-01 | Information Disclosure (secret leak via marker) | SummaryMarker | mitigate | `SummaryMarker` renders a FIXED Korean label per known category (`AUTH_ERROR`→'인증 오류', `RATE_LIMITED`→'레이트리밋') and returns null otherwise — it never echoes the raw `summaryMessage` value, and the backend response carries no secret field by design (DASH-02). No token/stack/secret path to the DOM exists. |
| T-0801-02 | Tampering / XSS (rendering API status string) | StatusBadge | mitigate | The unknown-status fallback renders the raw `status` string as a React text child (JSX-escaped); no `dangerouslySetInnerHTML`. The value is also zod-validated as a string upstream (07-02 collectionHealthSchema), so no markup injection is possible via a crafted status. |
| T-0801-03 | Spoofing (misread status grade) | StatusBadge | mitigate | Each grade pairs a distinct semantic color WITH a distinct Korean text label and lucide icon (never color-only/icon-only), so color-blind or grayscale viewing still distinguishes 정상/일부 실패/전체 실패/수집 대기 (08-UI-SPEC a11y) — a degraded/failed pipeline cannot visually masquerade as healthy. |
