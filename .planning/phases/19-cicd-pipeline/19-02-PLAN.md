## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runner ↔ VM | Tailscale 프라이빗 tailnet 경유 SSH(키 기반). 공개 SSH(22) 개방 불필요 |
| VM ↔ GHCR(private) | VM의 1회 `docker login`(read:packages PAT, VM 로컬)로 pull. PAT는 CI 미주입 |
| Runner ↔ 앱 시크릿 | `.env.prod`은 VM에만. deploy job은 앱 시크릿·GHCR PAT 미접근 |
| 시크릿 전달 | GitHub secrets → `env:`로만(shell 인터폴레이션 금지) → 로그 마스킹·인젝션 방지 |
