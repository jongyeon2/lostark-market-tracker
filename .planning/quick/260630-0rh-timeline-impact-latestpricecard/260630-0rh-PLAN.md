# Quick 260630-0rh: Timeline·Impact LatestPriceCard 긴 품목명 세로 잘림 수정

## 문제

Phase 14-02에서 `LatestPriceCard`(Timeline·Impact 공유 정체성 카드)의 CardTitle을
`text-xl` + [ItemIcon][displayName][RoleBadge] flex 행으로 변경했다. 이 카드는 `w-fit
min-w-56`(≈224px) 좁은 폭이라, "상급 아비도스 융화 재료" 같은 긴 큐레이션 이름이
글자 단위로 세로 줄바꿈("상급/아비/도스/융화/재료")되고 아이콘·배지가 가운데 끼어
깨진다(playwright `timeline-before.png` 확인). 원래 짧은 이름("수호석 조각")용 설계.

## 수정

`frontend/src/features/_shared/LatestPriceCard.tsx` CardTitle만:
- 제목 폰트 `text-xl` → `text-base` 축소(텍스트가 너무 큼)
- displayName span에 `whitespace-nowrap` 추가 → 한 줄(가로) 유지, `w-fit` 카드가 가로로 확장

Dashboard `ItemCard`는 별도 컴포넌트(그리드, 넓은 폭)라 미수정. 데이터·계약 무변경.

## Verify

- `npm run build`(tsc -b && vite build) 그린
- playwright로 Timeline·Impact 재캡처 → 제목이 가로 한 줄, 세로 잘림 해소
