## 4. 재련 재료 CategoryCode 실측 + ⚠ 플랜 D-04 전제 정정

`GET /markets/options` 실측 카테고리 트리(강화 재료 50000 하위):

| Code | CodeName |
|------|----------|
| 50010 | **재련 재료** |
| 50020 | 재련 추가 재료 |
| 51000 | 기타 재료 |
| 51100 | 무기 진화 재료 |

- **운명의 파괴석/수호석 결정은 `50010`(재련 재료)에 실재**한다(50020/기타에는 없음).
- ⚠ **플랜 D-04는 "운명 결정 CategoryCode ≠ 50010(융화재료)"로 가정했으나, 실측은 `50010`이다.** 실 트리에서 `50010`의 CodeName은 "융화재료"가 아니라 **"재련 재료"**이며 운명 결정이 여기 속한다(12-SPIKE-FINDINGS의 "융화재료=50010" 라벨링은 CodeName과 불일치했던 것). **영향:** roleGroup=MATERIAL·라벨 '재료'(D-04 결론)는 그대로 유효 — category_code 값 전제만 정정하면 되고, 카드는 category를 표기하지 않으므로(Phase 16 D-01) 사용자 영향 0. 17.1-02 전사 시 두 재료의 category는 실측대로 `50010`.
- 기존 유지 재료(아비도스 `6861012`·상급 아비도스 `6861013`)는 재실측 대상 아님(유지) — 현재 category 무변경.
