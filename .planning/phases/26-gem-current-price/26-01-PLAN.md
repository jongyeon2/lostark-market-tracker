# Phase 26-01 — 보석 현재가 둘러보기 `/gems` (GEM-02)

## 근거 (전부 Phase 24 실측)

`24-SPIKE-FINDINGS.md`가 이 계획의 모든 상수를 공급한다. **여기서 새로 추측하는 값은 없다.**

- 보석 = `CategoryCode 210000`(leaf) · `ItemTier=4` · 이름 정확검색(`"8레벨 겁화의 보석"`)
- **현재가 = `min(BuyPrice)`** = `Sort=BUY_PRICE` + `SortCondition=ASC` + `PageNo=1` → `Items[0].AuctionInfo.BuyPrice`
- **`Id` 없음** → 워치리스트 모델 재사용 불가, 이름이 키
- **`Level`은 아이템레벨(1640)** → 보석 레벨은 이름에만
- **레이트리밋 버킷 거래소와 공유** → 캐시 필수, 1보석=1콜(6콜/refresh)
- `BuyPrice` **null 가능**(입찰 전용 매물) — ASC가 null을 뒤로 보내므로 `Items[0]`이 항상 실제 최저가

## 설계 결정

**온디맨드 캐시(폴러 없음).** 뉴스(17.2)는 6h 스케줄 폴러지만 보석은 다르다: 뉴스는 대시보드 방문자
전원이 보지만 보석은 전용 페이지다. 폴러를 돌리면 **아무도 안 보는 시간에도 수집 버킷을 영구히 깎는다**.
캐시 미스에만 6콜 → 무방문 시 호출 0.

**부분 실패도 캐시한다.** 6종 중 3종만 성공해도 그 스냅샷을 캐시한다. 실패분만 캐시에서 빼면 요청마다
실패 보석을 재조회해 **버킷을 반복해서 태운다**. 5분 뒤 자연히 재시도된다.

**혼합 금지 원칙 승계.** 보석의 "최저 즉시구매가"는 거래소 `min_price`(최저 호가)와 **의미가 대응**하지만
(24 findings) **같은 테이블·같은 시리즈에 섞지 않는다** — 보석은 `price_snapshot`에 한 줄도 쓰지 않는다.

## 실행 중 발생한 편차 (기록)

**1. 공유 토큰 버킷 누락 → 라이브 429 (수정 완료).** 초안 Task 1/2는 `LostarkAuctionClient`가 그냥
호출하게 뒀다. 첫 라이브 실행에서 **겁화 3 OK / 작열 3 × HTTP 429**. 원인: 이 프로젝트엔 이미
`RedisTokenBucket`(단일 전역 버킷, `"one API key, one bucket"` D-03)이 있고 수집기·백필 러너가 호출 전
`tryAcquire`로 토큰을 얻는데, **보석만 그걸 우회**했다. 스파이크로 버킷 공유를 측정해놓고 코드에서
안 쓴 것. → `GemService.fetchOne`이 같은 버킷에서 토큰을 얻고, 못 얻으면 **호출 없이** `RATE_LIMITED`.

**2. `RATE_LIMITED` 상태 신설.** "고장"과 "수집에 예산을 양보함"은 사용자에게 다른 사실이라 문구를
분리("불러오지 못함" vs "잠시 후 다시"). 서버 측 429도 같은 의미이므로 같은 상태로 매핑.

**3. 레이트리밋 스냅샷은 캐시하지 않는다.** `OK`/`NO_BUYOUT`/`FETCH_FAILED`는 경매장이 준 **답**이라
캐시가 맞지만, `RATE_LIMITED`는 **묻지도 않은 것**이다. 5분 굳히면 몇 초 뒤 토큰이 회복돼도 열화가
지속되고, 재시도 비용은 0이다(토큰 없으면 네트워크에 안 나감).

**4. 공유 리미터 자체는 건드리지 않았다(스코프 밖).** 버킷은 용량 90 + 리필 90/분이라 **한 분에 최대
180콜**이 가능한데 서버 한도는 100/분이다 — 즉 리미터를 지켜도 429가 날 수 있다. 이건 Phase 2부터
있던 성질이고 수집기는 `Retry-After` 재시도로 흡수한다. 고치려면 Core Value 코드를 수정해야 하므로
**보고만 하고 손대지 않는다**(GEM-02의 "수집 0줄" 가드).

**5. `AsyncBoundary.pendingFallback`은 존재하지 않는다.** UI-SPEC 초안의 6행 Skeleton 조항은 공용
컴포넌트 수정을 요구하는데 같은 문서가 "0줄 수정"을 약속했다 → `NewsPanel` 관례대로 기본 `LoadingState`.
