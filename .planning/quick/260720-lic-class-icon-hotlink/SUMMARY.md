# Quick Task 260720-lic — 직업 아이콘 번들 → CDN 핫링크

## 무엇을 바꿨나

`frontend/public/class-icons/` **30개(328KB) 삭제**, `classIconUrl()`이 공식 CDN 절대 URL을 돌려주게
바꿨다. 아이템 아이콘이 원래 쓰던 패턴과 같아졌다 — 저장소는 이제 로스트아크 에셋을 **한 바이트도
보관하지 않는다.**

## 핵심 결정 · 근거

- **`260720-fn3`의 "번들" 결정을 뒤집었다.** 그때 근거(사이트 내부 자산이라 이동 가능)는 여전히
  맞지만, 저장소가 public이 되면서 '보관'이 '타인에게 제공'으로 바뀐다. 약관상 제재가 **API 접근
  권한 제한**이라 링크 깨짐(폴백이 받음)보다 훨씬 무겁다.
- **흰색 5개를 파일 수정이 아니라 CSS로 풀었다.** 핫링크는 원본을 못 바꾼다. 단색 아이콘이므로
  `brightness-0`으로 30개를 전부 검정으로 눌러 통일하고 다크에서 `invert`로 뒤집는다 — 원본이
  `#222222`든 `white`든 결과가 같다. 슬러그별 예외 표를 두지 않아도 되고, 나중에 스마일게이트가
  원본 색을 바꿔도 화면은 안 깨진다.
- **CSP를 넓히지 않았다.** `cdn-lostark.game.onstove.com`이 이미 `img-src`에 있었다(아이템 아이콘과
  같은 호스트). 넓혀야 했다면 전제부터 다시 봤을 것이다.

## 검증

- `npm run build` 통과.
- 라이브(dev, 1920): 아바타 페이지 `img[src*=cdn-lostark]` **30개 · 로드 실패 0 · 남은 로컬 경로 0**.
- 계산된 필터: 라이트 `brightness(0)` / 다크 `brightness(0) invert(1)`.
- 스크린샷 육안 확인 — 라이트·다크 양쪽에서 **30개 전부 보인다.** 예전에 안 보이던 5개
  (디스트로이어·워로드·홀리나이트·차원술사·가디언나이트) 포함.
- 콘솔 에러 0.

## 알려진 대가

- 아이콘이 `#222222` → `#000000`으로 아주 조금 진해졌다(`brightness-0`이 색을 눌러서). 육안으로는
  구분되지 않는 수준.
- ⚠️ **깨질 수 있는 링크다.** 경로에 `2018/obt`가 박힌 레거시 자산이라 사이트 개편 시 사라질 수
  있다. 그때는 `ClassIcon`의 `onError`가 아이콘 자리를 비우고 이름만 남긴다 — 레이아웃은 안 밀리고
  기능도 안 죽는다. 이게 이 결정에서 감수하기로 한 리스크다.
- 첫 로드 시 외부 요청 30건이 늘었다(`loading="lazy"`, 아이템 아이콘도 같은 방식).

## 범위 밖

- 아이템·보석 아이콘 — 원래부터 API가 준 `iconUrl` 핫링크라 손댈 것이 없다.
- 자체 아이콘 제작 — 공식 아이콘이 주는 식별성을 대체하지 못한다.
