# Phase 21 — 스펙업 재련 재료 카탈로그 스파이크 (거래소 MARKETS)

**Date:** 2026-07-14
**Endpoint:** `GET /markets/options` + `POST /markets/items`(카테고리별 이름검색) — 실 API, `.env` LOSTARK_API_KEY, HTTP 200
**How captured:** `MarketsApiSpikeTest.captureHoningMaterialCatalog()`(spike 프로파일, `@Disabled`) — 콘솔 출력만, **공개 메타데이터(Id/Name/Grade/Icon/Category)만** 캡처(가격·키 제외, `printItemFields`가 가격 필드 미출력). Testcontainers 컨텍스트로 부팅, 약 35콜(전부 200, 레이트리밋 100/min 여유).
**목적:** 재련 재료를 워치리스트에 편입(Phase 22)하기 전, 실 `external_item_id`·`category_code`·`icon`을 잠근다(Phase 12 spike-then-lock 계승).

> **보안 원칙(불변):** 실 JWT는 env(`LOSTARK_API_KEY`)에서만. `.env` gitignored·커밋 0. findings엔 공개 메타데이터만.

---

## 핵심 발견

1. **재련 기본 재료 = CategoryCode `50010`(재련 재료)** — 파괴석·수호석·돌파석·파편·융화재료가 여기 있음.
2. **재련 추가 재료 = CategoryCode `50020`(재련 추가 재료)** — **숨결(용암/빙하)** + **상급재련(야금술/재봉술)** 이 여기 있음(50010 아님).
3. **🔑 아크그리드 젬 = CategoryCode `230000`(거래소!)** — **경매장(AUCTIONS) 아님.** 질서/혼돈 젬이 거래소에서 이름검색됨. → **스코프 갱신**: 아크그리드젬은 거래소라 Phase 22(추적)로 처리 가능, 경매장(Phase 24)은 **보석(gems)만** 필요.
4. `51000`(기타재료)엔 이 재료들 없음(전부 0건).
5. 아이콘은 전부 `cdn-lostark.game.onstove.com/efui_iconatlas/use/<file>.png`, 서로 **구별됨**(각인서와 달리 재료·젬은 iconUrl distinct).
