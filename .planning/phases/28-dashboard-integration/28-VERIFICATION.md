## 🔑 검증이 잡아낸 것 — 모바일 겹침 (수정 완료)

375px 첫 렌더에서 **품목 이름이 사라지고 '딜러' 뱃지가 가격 위에 겹쳤다.** 실측:

```
카드 296px · 버튼 콘텐츠 177px(패딩 48 제외)
  가격 블록 163px (shrink-0)
  이름 블록   0px  ← 완전히 짜부라짐 → 자식(아이콘·뱃지)이 밖으로 넘쳐 가격 위에 페인트
  차트 링크  69px
```

**배포된 구버전과 비교해 원인을 갈랐다**(추측하지 않고 실측):
- 구버전(라이브)도 375px에서 **이름이 안 보인다** → 이름 실종은 **Phase 28 이전부터 있던 버그**
- 구버전은 겹치진 않는다 → **겹침은 내 차트 링크(69px)가 만든 것**

내가 만든 겹침을 고치려면 이름 블록에 자리를 줘야 하고 **그게 곧 원래 버그의 수정**이라 함께 했다:
`flex-1 min-w-0` + `<sm` 세로 스택 + `px-4 sm:px-6`.

**결과**: 이름 블록 0 → **193px**, 이름 **111px 표시**, 겹침 **0**, 데스크톱 회귀 **0**(가로 한 줄 유지·
이름 전체 표시·박스 416px 유지).

## 🔑 예고한 어긋남이 실측으로 확인됨 (설계대로)

박스 높이를 416px 고정으로 잡으며 "쿠폰 수가 바뀌면 어긋난다"고 고지했는데, **환경 차이로 이미 관측됐다**:

| 환경 | 쿠폰 | "첫 이벤트 카드 아래" |
|---|---|---|
| 라이브(운영) | 1개 | **417px** ← 416px 박스와 일치 |
| 로컬 dev | 2개 | **469px** (52px 밀림) |

쿠폰 하나가 52px을 민다. **416px은 운영 기준으로 맞춘 값**이라 유지한다(사용자 승인 2026-07-15).
두 박스의 **상단은 항상 88px로 정확히 정렬**되므로 어긋남은 하단에서만, 우측 패널 안에서만 보인다.
