| Threat ID | Category | Component | Disposition | Mitigation Plan |

Acceptance criteria assert no `bearer <token>` literal in committed files. HIGH severity if leaked → blocking checkpoint gates the model lock. |
| T-03-02 | Spoofing/Repudiation | 401 (expired/invalid token) misread as data finding | mitigate | Spike must distinguish 401 from a valid empty payload and record it in findings (matches design Failure Modes 401 handling); does not lock the model on an auth error. |
| T-03-03 | Tampering | Untrusted external JSON parsed into model decisions | accept | Read-only spike; response is inspected/documented, not persisted. No injection path into the DB at this phase. |
| T-03-04 | Denial of Service | Spike spamming the rate-limited API | mitigate | Single manual call (one request), `@Disabled` by default; cannot run in a loop or in CI. |
| T-03-SC | Tampering | Dependency supply chain | accept | No new package-manager installs; RestClient ships with Spring added in 01-01. No legitimacy gate needed. |
