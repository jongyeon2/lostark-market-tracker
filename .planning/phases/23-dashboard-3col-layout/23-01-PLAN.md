<what-to-build>
신규 `categories.ts`: 카테고리 taxonomy를 roleGroup.ts와 동형으로 단일 출처화.
- 타입 `Category = { id, label, group }`(group='각인'|'재료'), leaf 7종 정의 순서: dealer(딜러 각인, roleGroup==='DEALER') · support(서포터 각인, SUPPORT) · 강화재료·재련재료·상급재련·재련보조·아크그리드젬(각 itemGroup===라벨).
- predicate: 각인 leaf=roleGroup 비교, 재료 leaf=itemGroup 비교. `roleGroup=null`/미지정 itemGroup 품목은 어느 leaf에도 매칭 안 됨(현행 미표시 유지).
- `deriveCategories(items)`: 데이터에서 count>0인 leaf만 순서대로 반환(각 {id,label,group,count}). 빈 leaf 제외 → 빈 그룹 자동 소멸.
- `filterByCategory(items, id)`: 선택 leaf predicate로 필터.
- `DEFAULT`/`firstNonEmpty(categories)`: 첫 비어있지 않은 leaf id.
순수 함수만(데이터 페칭·React 없음). export 타입/헬퍼로 CategoryNav·DashboardPage가 소비.
</what-to-build>
<how-to-verify>
tsc 그린. deriveCategories가 현행 49종에서 7 leaf(딜러11·서포터7·강화재료2·재련재료9·상급재련8·재련보조6·아크그리드젬6) 순서대로 반환. 빈 그룹 없음.
</how-to-verify>
