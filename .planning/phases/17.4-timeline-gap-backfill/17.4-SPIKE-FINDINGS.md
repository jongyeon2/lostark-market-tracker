# Phase 17.4 스파이크 — 로스트아크 상세 API `Stats[]` 백필 가능성

**Date:** 2026-07-07
**Endpoint:** `GET /markets/items/{id}` (실 API 호출, `.env` LOSTARK_API_KEY, HTTP 200)
**목적:** 서버 off로 생긴 타임라인 수집 공백을, 로스트아크가 보관하는 일별 시세로 정직하게 백필할 수 있는지 확인.

---

## (a) Stats 보관 깊이 — **14일 연속**

세 품목 모두 `Stats[]` length = **14**, 날짜 **06-24 ~ 07-07 (오늘 포함) 하루 1개씩 연속**.
- span 13일 + 오늘 = 14 엔트리, daily-contiguous 확인.
- → **백필 가능 범위 = 최근 14일.** 14일 초과 gap은 API에도 없어 복구 불가 → 장기 해결은 Phase 18 상시 배포(연속 수집). 백필은 보완.

## (b) AvgPrice 채움 여부 — **유동 품목만**

| 품목 | category | Stats | AvgPrice>0 | 비고 |
|------|----------|-------|-----------|------|
| 운명의 파괴석 결정 (66102007) | 50010 재료 | 14 | **14/14** | 07-07 1732.3·07-06 1711.8·07-05 1685.6 (TradeCount 4만~24만/일) |
| 아비도스 융화 재료 (6861012) | 50010 재료 | 14 | **14/14** | 07-07 127.9·07-06 128.2 (TradeCount 100만~450만/일) |
| 유물 원한 각인서 (65200505) | 40000 각인서 | 14 | **0/14** | AvgPrice=0, TradeCount=0 — 거래 없음 |

- **재료(융화재료)는 14일 전부 실 일별 평균가**가 있음.
- **각인서(40000)는 AvgPrice=0** — 거래가 없어 일평균이 없음. 0으로 백필하면 왜곡.

## (c) 지표 불일치 — avg(거래) vs min(호가)

- Stats `AvgPrice` = 일별 **거래** 평균가. 현재 `price_snapshot.min_price` = 실시간 **최저 호가**(`CurrentMinPrice`).
- 유동 품목은 근사(파괴석 avg 1732 vs 실측 min 1685)하지만 **동일 지표 아님**.
- → 타임라인에서 min_price 라인과 섞으면 부정직. **별도 "일별 평균" 시리즈로 두고 "실측 vs 백필" 시각 구분** 필요.

## (d) 레이트리밋

- `x-ratelimit-limit: 100`, 1콜 후 remaining 98. 품목당 1콜(상세) → 25품목이면 25콜. 백필은 일회성/저빈도라 여유.

---

## 설계 함의 (phase discuss/plan에서 확정할 결정)

1. **저장:** 별도 `item_daily_stats(item_id, stat_date, avg_price, trade_count)` 테이블(Task 0 예비안). `price_snapshot`(Core Value 가드)은 건드리지 않음 — additive.
2. **표시:** 타임라인에 "일별 평균(백필)" 시리즈를 실측 min_price와 **구분**(색/점선/툴팁 "백필·일평균"). 또는 별도 토글.
3. **각인서 처리:** AvgPrice=0(거래 없음) 날은 백필 제외 — 각인서는 gap이 남음(유동 품목 위주).
4. **트리거:** 서버 기동 시 + 일 1회, 최근 14일 Stats fetch → 없는 날만 upsert(멱등). 실 수집 min_price는 그대로.
5. **범위 한계 명시:** 14일 초과 gap은 복구 불가 → Phase 18 상시 배포로 미래 gap 방지(보완 관계).

## Exit-gate — **PASS (조건부)**

- ✅ API가 14일 일별 시세를 실제로 제공 → 백필 **가능**.
- ⚠️ 단, **유동 품목·14일·avg 지표**로 한정. "모든 gap을 min_price로 채운다"는 불가.
- → 실현 스코프: **"유동 품목의 최근 14일 gap을 별도 일별-평균 시리즈로 정직하게 채운다."**
