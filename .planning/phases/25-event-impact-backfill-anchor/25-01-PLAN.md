# Phase 25-01 — event-impact 백필 폴백 앵커 (IMPACT-V2-01)

## 문제 (실측)

`EventImpactService`는 `price_snapshot`만 읽는다. Phase 17.4가 BACKFILL-04로 "event-impact 0줄"을
의도적으로 가드했기 때문이다. 그 결과 **수집 시작(2026-07-10T14:00Z) 이전 이벤트는 앵커가 0건**이라
영원히 `insufficient_data · 희소`다.

운영 실측: `/api/items/9/event-impact?window=24` → `preAnchorAt`·`postAnchorAt` **모두 null**.
같은 품목 타임라인 백필: **7/7 32,628 → 7/8 45,877(+40.6%) → 7/14 40,483**. 데이터는 있는데
영향 페이지만 못 본다.

## 결정 (사용자 승인)

**폴백 앵커** — 스냅샷 앵커가 있으면 지금처럼 min 기준, 없을 때만 일별 평균으로 계산하고
"일별 평균 기준"이라고 표기.

- **앵커 규칙**: `pre` = 이벤트 발생일 **전일**(KST) 일평균, `post` = 이벤트 발생일 **당일**(KST) 일평균.
  스냅샷 규칙(직전/직후)의 일별 대응이며, 승인된 미리보기(7/7 → 7/8 = +40.6%)가 이 규칙이다.
- **신선도**: ±30분 게이트는 일별 데이터에 원리상 적용 불가(일별 포인트는 자정 기준 → 최대 12h 차이).
  일별 소스 전용 규칙 = 두 앵커가 `ceil(window/24)`일 이내. window=24 → ±1일.
- **자료원 우선순위**: 같은 날짜에 `DETAIL_STATS`와 `YDAY_AVG`가 공존한다(UNIQUE는 source 포함).
  **`DETAIL_STATS` 우선** — 로아가 보관한 값이라 수집 이전 날짜까지 소급되고(정확히 이 phase가 푸는
  구간), 전 기간을 **같은 자료원**으로 덮어 pre/post의 기준이 어긋날 수 없다. `YDAY_AVG`는 그 날짜에
  DETAIL_STATS가 없을 때만.
- **혼합 금지**: pre와 post가 **같은 자료원**일 때만 계산한다. 한쪽만 스냅샷이면 폴백 전체를 쓴다.

### Task 1 — 백엔드: 폴백 앵커 + 자료원 표기

**files:**
- `src/main/java/com/lostark/tracker/web/dto/EventImpactItem.java` (수정)
- `src/main/java/com/lostark/tracker/read/EventImpactService.java` (수정)
- `src/test/java/com/lostark/tracker/read/EventImpactBackfillAnchorIT.java` (신규)

**action:**
1. **실패 테스트 먼저** — 스냅샷 없는 과거 이벤트 + 일별 스탯 2점 → `ok` + `changeRate` +
   `anchorSource=DAILY_AVG`. 스냅샷 있으면 `SNAPSHOT_MIN`이고 값 불변. 한쪽 일자 결측 → 여전히
   `insufficient_data`. DETAIL_STATS/YDAY_AVG 중복 시 DETAIL_STATS 채택. window 확장 규칙.
2. `EventImpactItem`에 `anchorSource` 추가(`SNAPSHOT_MIN`/`DAILY_AVG`/`null`).
   `prePrice`/`postPrice`는 `Long` → 일평균은 소수라 **반올림해서 담되** 자료원 필드로 구분(스키마 확장
   최소화). *(대안이던 BigDecimal 승격은 프론트 계약까지 흔들어 이번 스코프 밖.)*
3. `EventImpactService`: 스냅샷 앵커 판정 후 실패 시 일별 폴백. 일별 스탯도 **단일 범위 조회 1회**
   (`findByTrackedItemIdAndStatDateBetweenOrderByStatDateAsc`, min일-1 ~ max일+1)로 읽고 메모리에서
   `(date → avg)` 맵 구성(N+1 회피, D-09 유지). `DETAIL_STATS` 우선 병합.
4. javadoc: 자료원 계약·혼합 금지·KST 일자 판정 명시.

**verify:** `./gradlew test --tests '*EventImpact*'` 그린
**done:** 스냅샷 있는 이벤트는 값 불변, 없는 과거 이벤트는 일별 평균으로 `ok`.
