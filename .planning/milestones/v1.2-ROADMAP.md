# Milestone v1.2: Item Visual/Data Enrichment

**Status:** ✅ SHIPPED 2026-06-30
**Phases:** 12-14
**Total Plans:** 6

## Overview

v1.1이 세운 데모 대시보드 3화면(Dashboard / Item Timeline / Event Impact)과 셀렉터에 **품목 아이콘·역할 그룹 메타데이터**를 입히고, **융화재료 + 큐레이션된 딜러/서포터 유물 각인서**(최종 15개)를 watchlist·seed 데모에 추가했다. enrichment는 수집·캐시·event-impact 계산을 **0줄도 건드리지 않는 read-path additive 한 겹**이며, **API 키 없이 seed만으로** 아이콘까지 재현된다. 순서: 실 API로 데이터를 잠그는 스파이크(12, 게이트) → 백엔드 enrichment 컬럼·DTO·seed 확장(13) → 프론트 아이콘·fallback·docs(14). 아이콘 출처는 **API `Icon` URL을 DB에 적재**(스파이크 캡처 상수), 프론트는 `<img onError>` + 고정 슬롯 역할색 글리프 fallback으로 핫링크 장애를 흡수한다.

## Milestone Summary

**Decimal Phases:** 없음 (12 → 13 → 14 선형).

**Key Decisions:**

- spike-then-lock 재사용(D-12): 실 API 1회 실측으로 데이터 잠금, 런타임 키 불필요 — v1.0 Task 0 동형.
- 아이콘 출처 = API `Icon` URL → DB 적재(번들 아닌), 프론트는 onError fallback 흡수 — 에셋 수급·번들 부담 회피.
- enrichment = read-path additive only(D-07): 수집/캐시/event-impact 0줄 — Core Value(수집 신뢰성) 보호.
- 각인서 동일 글리프(11종) → fallback 대체 않고 실아이콘 + 한글 라벨 + 역할 배지로 식별(D-05/D-06).
- 역할색 = semantic 색군(rose/emerald/amber), accent(blue-600)와 분리(D-01); 역할 배지 solid 처리로 상태(tinted)·이벤트(outline) 배지와 구별(D-04).
- roleGroup = z.enum nullable로 미상 값 boundary loud-fail(D-06).
- 그룹 필터 컨트롤은 v2 — v1.2는 역할 배지 + 셀렉터 그룹 헤더로 대체.
