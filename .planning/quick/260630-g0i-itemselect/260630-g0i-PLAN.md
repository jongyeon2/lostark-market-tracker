# Quick 260630-g0i: ItemSelect 트리거 카테고리명만 표기

## 문제

Timeline·Impact 페이지의 `ItemSelect` 드롭다운 트리거가 선택된 품목의 긴 displayName
(예: "유물 저주받은 인형 각인서")을 그대로 표시해 폭(w-72)을 넘겨 잘림. 260630-16d에서
폭을 넓혔지만 긴 이름엔 여전히 부족.

## 결정 (확인됨)

- 트리거에는 **상위 카테고리 라벨만** 표기(roleGroup → ROLE_LABEL: 딜러/서포터/융화재료, null은 기타).
- 드롭다운 목록(SelectItem)은 개별 품목(아이콘+이름+배지) 그대로 — 모든 품목 선택 가능.
- 정보 손실 없음: 선택된 실제 품목명은 같은 페이지 `LatestPriceCard`에 아이콘+이름+배지로 표시됨
  (TimelinePage.tsx:151-156, ImpactPage.tsx:146-151 확인).

## 수정 (단일 태스크)

**Task 1 — `frontend/src/features/_shared/ItemSelect.tsx`**
- `value`로 선택된 item을 찾아, 트리거에 `roleGroup ? ROLE_LABEL[roleGroup] : '기타'`만 렌더
  (Radix `SelectValue`의 선택값 자동 복제 대신 `SelectTrigger` children 직접 제어).
- 미선택 시 placeholder "품목 선택" 유지.
- 트리거 폭 `w-72` → 카테고리명에 맞게 좁힘(`w-40`), pending Skeleton·error trigger 폭도 정합.
- `ROLE_LABEL`/`RoleGroup`은 이미 import됨. 목록 렌더(SECTIONS/SelectItem) 무변경.

- `npm run build`(tsc -b && vite build) 그린.
- playwright(5173, dev 실데이터): Timeline 트리거가 카테고리명만 한 줄로 표시(잘림 0),
  드롭다운에서 다른 품목 선택 시 트리거 라벨이 해당 카테고리로 바뀌고 LatestPriceCard에 품목명 반영.
