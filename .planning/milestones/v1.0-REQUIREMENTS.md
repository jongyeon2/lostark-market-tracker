# Requirements: 로스트아크 거래소 시세 수집·분석 파이프라인

**Defined:** 2026-06-20
**Core Value:** 레이트리밋이 걸린 외부 마켓 API에서 시세를 빠짐없이 수집해 시계열로 쌓고, 캐시로 안정적으로 서빙한다

## v1 Requirements

초기 릴리스 범위. 각 항목은 로드맵 페이즈에 매핑된다.

### Collection (COLL)

- [x] **COLL-01**: 스케줄러가 10분 주기(`fixedDelay`)로 거래소 시세를 수집한다
- [x] **COLL-02**: 한 수집 틱은 카테고리 호출을 병렬 팬아웃한 뒤 전부 완료를 기다리며(per-call 타임아웃), `fixedDelay`가 틱 중복 실행을 막는다
- [x] **COLL-03**: 레이트리밋(Redis 토큰버킷 또는 Bucket4j)을 초과하지 않으며, 재시작 후 토큰 수가 올바르게 복원된다
- [x] **COLL-04**: API 429는 Retry-After + 지수 백오프 + 최대 3회 재시도 후 해당 품목을 스킵하고, 401(토큰 만료)/5xx는 구분 처리한다
- [x] **COLL-05**: 품목 수집 실패 시 스냅샷을 쓰지 않고(구멍 허용) 실행 결과만 기록한다

### Data (DATA)

- [x] **DATA-01**: price_snapshot이 시계열로 적재되고 `UNIQUE(tracked_item_id, collected_at)`로 중복 없이 멱등하다
- [x] **DATA-02**: 모든 시간 필드가 UTC PostgreSQL `TIMESTAMPTZ`로 저장된다(collected_at / fetched_at / created_at / updated_at)
- [x] **DATA-03**: tracked_item이 안정적 `external_item_id` + `display_name`으로 품목을 식별한다 (Task 0에서 매칭 규칙 확정)
- [x] **DATA-04**: collection_run이 각 수집 실행의 시작/종료 시각과 성공/실패 카운트를 기록한다

### Read API (API)

- [x] **API-01**: GET /api/items로 워치리스트 품목을 조회한다
- [x] **API-02**: GET /api/items/{id}/latest로 Redis 캐시된 최신가를 조회하며, 스냅샷 쓰기 시 캐시가 무효화된다
- [x] **API-03**: GET /api/items/{id}/prices?from=&to=로 기간 스냅샷과 겹치는 이벤트를 함께 반환한다
- [x] **API-04**: 큰 범위 조회는 서버 측 다운샘플(버킷 집계)로 점 수를 제한해 반환한다
- [x] **API-05**: 잘못된 입력(from>to, window<=0, 없는 itemId, 빈 범위)에 적절한 4xx 또는 빈 결과를 반환한다

### Events & Admin (ADMIN)

- [x] **ADMIN-01**: 관리자가 게임 이벤트(로아온/대형 업데이트/시즌 종료/밸런스 패치)를 등록·수정·삭제한다(created_at/updated_at 기록)
- [x] **ADMIN-02**: 관리자가 워치리스트 품목을 등록·삭제한다
- [x] **ADMIN-03**: 모든 /api/admin/** 엔드포인트는 공유 시크릿 인증 뒤에 있다

### Event Impact (IMPACT) — 2주차 말 하드 게이트 통과 조건부

- [x] **IMPACT-01**: GET /api/items/{id}/event-impact?window=Nh가 이벤트별 ±N시간 전후 가격 변화율(v1 지표)을 계산해 반환한다
- [x] **IMPACT-02**: 윈도우 데이터가 희소하거나 앵커가 staleness 허용치 밖이면 `insufficient_data`를 반환하고, 사용한 앵커 시각을 응답에 포함한다

### Ops (OPS)

- [x] **OPS-01**: GET /api/health/collection이 마지막 수집 시각과 성공/실패 카운트를 노출한다

### Distribution (DIST)

- [x] **DIST-01**: docker-compose로 Postgres+Redis를 띄워 리뷰어가 로컬에서 재현할 수 있다
- [x] **DIST-02**: GitHub Actions CI가 Testcontainers(Postgres+Redis)로 빌드+테스트를 자동 실행한다
- [x] **DIST-03**: 격리된 시드 데이터(synthetic 플래그/프로파일)로 타임라인·event-impact를 빈 화면 없이 데모한다
- [x] **DIST-04**: README가 아키텍처 다이어그램·설계 트레이드오프·curl 예시·샘플 JSON 응답·로컬 실행·시드 모드·보존 정책 한 줄을 포함한다

## v2 Requirements

향후 릴리스로 연기. 추적하되 현재 로드맵엔 없음.

### Analysis
- **IMPACT-V2-01**: 카테고리 베이스라인 대비 초과 상승률 비교
- **IMPACT-V2-02**: event-impact median/스무딩(노이즈 완화)

### Observability
- **OPS-V2-01**: Micrometer 카운터(429 / skipped tick / failed item / cache hit·miss) — *시간 남으면 MVP 끝물, 아니면 v2*

### Config
- **CFG-V2-01**: 매직 넘버 `@ConfigurationProperties` 외부화(수집 주기·풀 크기·토큰버킷 레이트·재시도 수·충분성 임계치)

### Events / Sources
- **EVT-V2-01**: 기간형 이벤트(start/end) 모델
- **SRC-V2-01**: 경매장(AUCTIONS) / 보석

### Automation / Scale / Auth / Deploy
- **AUTO-V2-01**: 자동 뉴스 파싱 · 이벤트 자동 추출 · 알림
- **SCALE-V2-01**: 롤업 / 파티셔닝 / 보존 정책 / 다중 인스턴스 HA
- **AUTH-V2-01**: 풀 유저 / 권한 모델
- **DEPLOY-V2-01**: Railway/Fly/Render 데모 배포

## Out of Scope

명시적 제외. 스코프 크리프 방지용.

| Feature | Reason |
|---------|--------|
| 별도 프론트엔드 UI | README curl + 샘플 JSON으로 대체 — 백엔드 포트폴리오 |
| MSA · Kafka · Spring Batch | 1개월/단일 인스턴스/첫 스케줄러·캐시 학습에 과한 고도 |
| 캐릭터 분석 | 거래소 시세 파이프라인과 무관 |
| MySQL 전용 SQL/타입 | DB는 PostgreSQL 확정 |
| 인과 주장(이벤트가 가격을 올렸다) | 상관 ≠ 인과 — 시점 상관까지만 |

## v1.0 Outcomes

모든 24개 v1 요구사항이 v1.0 MVP에서 배포·검증됨. 주요 결과 메모:

- **IMPACT-01/02** — 2주차 말 하드 게이트 통과로 진행(슬립 시 v2 강등 조건이었음). change_rate = post/pre−1 (min_price), 30분 staleness + sufficiency 가드로 sparse/stale을 `insufficient_data`로 구분. 상관까지만 — 인과 주장 없음.
- **COLL-03** — 레이트리밋은 자체 Lua 원자적 Redis 토큰버킷으로 구현(Bucket4j 대신), 재시작 후 토큰 복원 + fail-closed.
- **DIST-02** — CI는 로컬과 동일한 `./gradlew build`(전체 Testcontainers 스위트). Phase 6 UAT에서 Node 20 deprecation 경고 발견 → 액션 @v5 상향으로 정리(커밋 03584e0).
- **DATA-03** — Task 0 실측으로 확정: avg_price/trade_count는 일단위 전용(상세 Stats[]) → MVP는 min_price 유지, avg_price는 v2.
