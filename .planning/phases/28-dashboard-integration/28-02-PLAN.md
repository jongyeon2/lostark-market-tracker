# Phase 28-02 — 이벤트 영향 흡수 + 스크롤 박스 + 차트 링크 (DASH-02, DASH-03)

`이벤트 영향`은 **페이지를 옮겨가 셀렉터로 품목을 다시 골라야** 했다 — 대시보드에서 이미 그 품목을
보고 있었는데도. 카드를 누르면 바로 아래 뜨는 게 낫다(사용자 재설계 2026-07-15).

## 삭제 가능 여부 — 실측 확인 완료

`grep`으로 확인했다(추측 금지):

| 컴포넌트 | 판정 |
|---|---|
| `ImpactPage.tsx` | **삭제** — 조립만 하던 껍데기 |
| `useImpactParams.ts` | **삭제** — `ImpactPage` 전용(URL 상태 → 로컬 state로 대체) |
| `ItemSelect`·`LatestPriceCard` | **⛔ 유지** — `TimelinePage`가 실제로 import한다 |
| `WindowControls`·`CorrelationBanner`·`EventImpactTable/Cards`·`impactFormat` | **유지·재사용** |

`WindowControls`는 주석에서만 `useImpactParams`를 언급하고 **상태를 안 들고 있다**(dumb controlled) →
로컬 state에 그대로 물린다.

## 설계 결정

**416px 고정 높이**(사용자 승인 2026-07-15). 요청은 "소식 박스 위 선 ~ 첫 이벤트 카드 아래"였고
실측은 417px이지만 **그 지점은 고정이 아니다** — 소식 패널 맨 위가 쿠폰이라 관리자가 쿠폰을 6개
등록하면 ~637px로 밀린다. CSS엔 "옆 컬럼 특정 요소 아래에 맞춰라"가 없고, JS 측정은 리사이즈·데이터
변경마다 재측정하는 레이아웃 코드를 부른다 — **6개 값 정렬하자고 감수할 복잡도가 아니다.**
고정이라 어긋나도 **중앙 박스 높이는 항상 같아 화면이 흔들리지 않는다.**

**`ItemCard`를 버튼+링크 형제로 쪼갠다.** 지금은 카드 전체가 `<Link>`인데 그 안에 차트 링크를 넣으면
**interactive 중첩**이라 HTML이 깨지고 키보드 탭 순서가 무너진다. `<button>`(선택)과 `<Link>`(차트)를
형제로 둔다 — 둘 다 네이티브 요소라 Ctrl/가운데클릭 새 탭·Enter가 공짜로 따라온다.

**선택 상태를 색 단독으로 표시하지 않는다** — `CategoryNav`의 활성 패턴(`border-primary` + `bg-muted`
+ `aria-pressed`) 재사용. D-01 규율.

**보석 카테고리에선 이벤트 영향 섹션을 숨긴다.** 보석은 선택이 불가능하므로
"물품을 선택하면…" 안내조차 **거짓**이 된다.

## Tasks

### Task 1 — `ItemCard` 버튼 + 차트 링크

**name:** 클릭=선택, 차트는 형제 링크
**action:** `<Link>` 래퍼를 `<button>`(선택) + `<Link>`(차트) 형제로 분해. 가격 fan-out은 무변경.

**files:** `frontend/src/features/dashboard/ItemCard.tsx` (수정)

- props에 `selected: boolean` · `onSelect: (id:number) => void` 추가.
- 구조: `<Card><div class="flex"><button class="flex-1">[아이콘][이름][뱃지] … [🪙최저가][시각]</button>
  <Link to={`/timeline?item=${id}`}>차트</Link></div></Card>`
- 선택 표시: `aria-pressed` + `border-primary`/`bg-muted`(색 단독 금지).
- `useLatestPrice` per-card fan-out · `useCollectionHealth` 공유 · `Skeleton`/`최저가 수집 중`/
  `데이터 없음` 분기 **전부 무변경**.
- 차트 링크 아이콘: `lucide-react`(이미 의존) — 신규 의존 0.

**verify:** `npm run build` 그린.

**files:** `frontend/src/features/dashboard/ItemImpactSection.tsx` (신규)

### Task 3 — `DashboardPage` 스크롤 박스 + 영향 섹션

**name:** 중앙 컬럼 통합
**action:** 중앙을 `flex flex-col`로: [스크롤 박스] + [이벤트 영향].

**files:** `frontend/src/features/dashboard/DashboardPage.tsx` (수정)

- 신규 로컬 state: `selectedItemId: number | null`(기본 null) · `impactWindow: number`(기본 24).
  URL 동기화 없음(Phase 23 A4 YAGNI 승계).
- **카테고리 변경 시 `selectedItemId` 리셋** — `onSelect`에서 함께 처리.
