Output: `NewsPanel.tsx`에 쿠폰 섹션(복사 버튼·자체 AsyncBoundary) + 최상단 배치. 백엔드·lib 데이터 계층 diff 0줄(useCoupons는 17.3-02에서 이미 추가됨).
